## Notas para la siguiente sesión
- Rama de trabajo: `movil` (commits hasta `3dcb335`, sin push). Nunca `main`.
- Prettier no tiene `printWidth` en `.prettierrc` y el repo usa líneas de ~160; si se formatea un archivo existente con él, usar `--print-width 160` o el diff se llena de cambios que no importan.
- `overflow-x: auto` en un contenedor fuerza `overflow-y: auto` y dibuja una barra vertical alrededor de componentes que ya se deslizan solos: se quita el `overflow` del contenedor.
- `1fr` es `minmax(auto, 1fr)`: los `input` empujan la columna; usar `minmax(0, 1fr)`.
