# Lo que voy aprendiendo

Una nota corta por concepto, **escrita por mí, con mis palabras**. Sirve para repasar y como mi propia documentación del proyecto.

## Cómo funciona

- Cuando aparezca algo nuevo (un guard de NestJS, un JWT, una migración…), escribo una nota en esta carpeta.
- Nombre del archivo: el concepto en kebab-case, por ejemplo `jwt.md`, `server-components.md`, `centavos-no-decimales.md`.
- Le puedo pedir a Claude que la **revise**: que corrija errores o me diga qué me faltó, pero sin reescribirla por mí.

## Plantilla

```markdown
# Concepto

## Qué es
(en una o dos frases, como se lo explicaría a alguien)

## Para qué lo usamos en Kairo
(dónde aparece y qué problema resuelve)

## Ejemplo del proyecto
(archivo o fragmento donde se ve)

## Lo que me costó entender
(dudas, errores que cometí)
```
